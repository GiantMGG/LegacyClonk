**What to try** — five things to click in v370:

1. **Learn from the tutorial** — Start Game → Tutorial → Tutorial01: the tutorial now
   speaks; guided message boxes walk you through your first steps (v369 shipped it silent).
2. **Free Game** — main menu → Free Game: the round-setup dialog opens directly on the
   world-settings stage; pick a landscape, press Enter, and the round starts.
3. **Blueprints reach the round** — round setup → Store tab (Ctrl+Tab) → tick Windmill →
   Start: the windmill is buildable in the live round.
4. **Map scale** — world settings → the "Map scale" row (formerly "Zoom factor"): a clean
   "10 ×" readout with no garbled unit glyph.
5. **Auf Deutsch** — the welcome and pre-game dialogs render German with the DE language.
