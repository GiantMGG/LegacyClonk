# Cookbook

Copy-paste recipes for common modder tasks. Each recipe is a single page
with a "You will learn" summary, a numbered step list, and a "Complete
files" section.

## Recipes

- [Custom sword](custom-sword.md) — a melee weapon with a `Hit` callback.
- [Flammable object](flammable-object.md) — an object that catches fire.
- [Timer effect](timer-effect.md) — a stackable timed buff.
- [Scenario objective](scenario-objective.md) — a win condition.
- [Wire a menu](wire-a-menu.md) — a clickable context menu.
- [Make a scenario](make-a-scenario.md) — a playable scenario from scratch.
